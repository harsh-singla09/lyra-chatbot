# Lyra AI 🤖

Lyra is a personal AI assistant built using:

- Node.js
- Express
- Ollama
- JavaScript

## Features

- AI Chat
- Voice Input
- Voice Output
- Personalized Responses
- Conversation Memory

## Installation

```bash''
git clone <repo-url>
cd lyra-ai

Backend
cd backend
npm install
npm start
Ollama
ollama run llama3.2:3b
Frontend

Open:

frontend/index.html
